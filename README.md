# Course Dashboard

Дашборд преподавателя курса «Управление агентной разработкой»: автоматически читает `.md`-артефакты из 25 публичных репозиториев студентов, строит матрицу «кто что сдал» и LLM-агентом подсвечивает разрывы связности между артефактами. Проект строится live на занятиях курса как эталон агентной разработки.

## Стек

| Слой | Технология |
|---|---|
| Backend | Python ≥ 3.12, FastAPI, Uvicorn |
| ORM / миграции | SQLAlchemy 2.0 (Mapped), Alembic |
| БД | SQLite (WAL) |
| Шаблоны | Jinja2 + HTMX |
| Auth | bcrypt + signed cookies (single-user) |
| LLM | DeepSeek API (`deepseek-v4-flash`) |
| HTTP-клиент | httpx (async) |
| Тесты | pytest |
| Линтер | ruff |

## Запуск с нуля

```bash
# 1. Клонирование
git clone <url> && cd course-dashboard

# 2. Виртуальное окружение
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate

# 3. Зависимости
pip install -e ".[dev]"

# 4. Миграции (создаст course_dashboard.db + seed-админа)
alembic upgrade head

# 5. Сервер (port 8000)
uvicorn app.main:app --reload

# 6. Тесты
pytest

# 7. Линтер
ruff check .
```

> **Минимум для запуска:** переменные `CD_SECRET_KEY` и `CD_ADMIN_PASSWORD` заданы в окружении. Остальное имеет дефолты (см. `app/config.py`).

## Хуки и гейты (H1, #52)

Политика без машинного гейта не работает — гейты версионируются в [`hooks/`](hooks/) и включаются один раз:

```bash
git config core.hooksPath hooks
```

| Хук | Гейт |
|---|---|---|
| `commit-msg` | Изменение/удаление существующих файлов `tests/` блокируется без строки `tests-change: <обоснование>` в сообщении коммита (стандарт тестирования п.3: тесты — контракт). Новые тесты проходят свободно |
| `pre-push` (H1) | `ruff check .` + полная suite с coverage-гейтом: `pytest --cov=app`, порог `fail_under = 90` (pyproject) |
| `pre-push` (H2) | **Документационный гейт.** Блокирует push, если изменены файлы вне doc-файлов, но не обновлены doc-файлы — и ни один коммит push'а не содержит строку «докам обновление не требуется, потому что …». Doc-файлы: `README.md`, `INDEX.md`, `ARCHITECTURE.md`, `CLAUDE.md`, `data-model.md`, `CHANGELOG.md`, `docs/`, `.claude/`, `product/`, `decisions/`. `memory/MEMORY.md` исключён (рабочая память сессий, живёт отдельным ритмом). |

**Границы гейта (честно):** активация — opt-in на каждый клон (`core.hooksPath` не переносится с clone); `git commit --no-verify` и `git push --no-verify` обходят хуки; сами файлы `hooks/` гейтом не защищены; гейт файловый — «новые тесты свободно» означает только новые файлы (добавление тестов в существующий файл и merge-коммит с чужими правками тестов тоже требуют `tests-change:`); порог покрытия применяется только при запуске с `--cov` (обычный `pytest` порог не проверяет). Техническая неотвратимость — это CI-гейт на сервере; хуки — локальная дисциплина (материал занятия 14).

**Границы H2 (честно):** гейт смотрит только на список путей — он не умеет проверять, действительно ли изменение *затрагивает* то, о чём говорит документация (это семантическая задача). Если вы изменили код, но доки правда не нужно трогать — просто напишите в любом коммите push'а «докам обновление не требуется, потому что <причина>». Агент (человек) на ревью увидит эту строку и поймёт, что решение осознанное. Если вы считаете, что гейт ложно сработал — это ок, вы либо обновляете доки, либо пишете waiver. Ложное пропускание возможно, если doc-файл не входит в `DOCK`/`DOCDIR` — добавляйте туда новые doc-паттерны по мере роста проекта. Срабатывание на `origin/main` — гейт смотрит diff относительно мерж-бейза с main (для новых веток); если пишете прямо в main, гейт проверяет только последний коммит.

## Статус

Реализованы пять итераций (занятия 9–14 + пост-курсовые доводки). Ядро FR-5 работает (гейт Фазы 0 снят 2026-07-30, ADR-004 Accepted); вердикты — на русском (C4, принудительный пересчёт C5 через bump версий рубрик). **Главный экран `GET /` — матрица «репозиторий × артефакт»**: сводка строки (⚠ разрывы · X/M сдано · «мимо ревью»), три сортировки (по реестру / по разрывам / по отставанию), «сдано, но разрыв» с чипом ≤2 строк, легенда без жаргона, кнопка «обновить сейчас». Дубли artifact_def вычищены миграцией `e9d23a5c1f04` + guard в реконсиляции. Дизайн: бумага/чернила, serif-заголовки, моно для доказательных данных. Тестов 411. ## Деплой (VPS, ARCHITECTURE §5.5)

Обход по расписанию запускает системный cron (носитель FR-8 — ОС, не приложение):

```cron
# обход 2 раза в сутки; SYNC_TOKEN = значение CD_SYNC_TOKEN из окружения приложения
0 7,19 * * * curl -s -X POST http://localhost:8000/sync -H "X-Sync-Token: $SYNC_TOKEN"
```

Чек-лист деплоя: env-переменные (`CD_ADMIN_PASSWORD` — до миграции, сид админа читает её; `CD_SECRET_KEY`; `CD_SYNC_TOKEN`; `CD_GITHUB_TOKEN`/`CD_GITLAB_TOKEN` — read-only, NFR-3; `CD_TZ_OFFSET_MINUTES` — смещение отображаемого времени в минутах, например 240 для UTC+4, по умолчанию зона сервера) → `alembic upgrade head` → `uvicorn app.main:app` → загрузить реестр репозиториев (файл версионируется в репо; импорт идемпотентен — дубликаты отсеиваются по нормализованному URL):

```bash
curl -X POST http://localhost:8000/import-csv --data-binary @data/student-repos.csv -b cookies.txt
```

→ `POST /sync` (первый обход) → **проверить `crontab -l`** → `GET /health` показывает время последнего обхода (если cron сломан — отметка «актуально на» устаревает видимо, §5.5).

> Все интервью в основе требований — синтетические (ИИ играл персону); требования — приоритизированные гипотезы. Это учебная честность курса, зафиксированная в PRD §0.
